# Emails d'authentification (Supabase Auth)

Gabarits HTML en français, source de vérité versionnée ici (aucun secret). Ils sont appliqués par l'API de gestion Supabase (`PATCH /v1/projects/{ref}/config/auth`, champs `mailer_templates_*_content` et `mailer_subjects_*`) : inscription (`confirmation`), mot de passe oublié (`recovery`), lien de connexion (`magic_link`), invitation, changement d'adresse, ré-authentification. Le nom de marque « backleenks » y est écrit en dur : à remplacer si la marque change. Les gabarits en ligne doivent rester identiques à ces fichiers : après toute modification, les recoller dans Supabase (Authentication > Emails) ou les repousser via l'API de gestion. Expéditeur : SMTP Resend, domaine `ouiouioui.app` (provisoire).
